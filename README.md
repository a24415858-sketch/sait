# Мир Мебели

Сайт мебельной компании «Мир Мебели»: интерактивная главная страница, каталог с фильтрами и страница политики конфиденциальности. Чистые HTML, CSS и JavaScript — без сборки и без внешних зависимостей (шрифты и картинки лежат в проекте).

## Как посмотреть

Достаточно открыть `index.html` в браузере. Либо запустить локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Для публикации подойдёт любой хостинг статических сайтов, в том числе GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

## Что где лежит

| Файл | Что в нём |
| --- | --- |
| `index.html` | Главная: кухня-конструктор, категории, интерьер с точками, популярные модели, калькулятор, этапы, FAQ, заявка |
| `catalog.html` | Каталог: категории, поиск, сортировка, избранное, быстрый просмотр |
| `privacy.html` | Шаблон политики конфиденциальности (нужно вписать реквизиты) |
| `js/config.js` | **Контакты, соцсети, адрес приёма заявок** |
| `js/data.js` | **Категории и товары каталога** |
| `js/home.js` | Интерактив главной; в блоке `CALC` — цены для калькулятора, в `SPOTS` — точки на фото гостиной |
| `js/main.js` | Общая логика: меню, модальные окна, формы, избранное |
| `css/style.css` | Все стили; цвета и шрифты — в `:root` в начале файла |
| `assets/img` | Фото: `имя.jpg` (1264 px) и `имя-sm.jpg` (720 px, превью) |

## Что нужно заменить перед запуском

1. **Контакты** — телефон, почта, адрес, часы работы и ссылки на мессенджеры в `js/config.js`. Они подставляются на все страницы автоматически.
2. **Приём заявок** — в `js/config.js` укажите `formEndpoint` (адрес сервиса или своего обработчика, принимающего JSON методом POST). Пока поле пустое, форма открывает у посетителя почтовую программу с готовым письмом.
3. **Товары и цены** — `js/data.js`. Сейчас там демонстрационные модели и цены.
4. **Цены калькулятора** — объект `CALC` в `js/home.js`.
5. **Сроки, гарантия, условия** — цифры в первом экране, блоке этапов и FAQ в `index.html`.
6. **Политика конфиденциальности** — реквизиты в `privacy.html`.
7. **Фотографии** — сейчас используются сгенерированные изображения. Замените их фотографиями своих работ, сохранив имена файлов, либо укажите новые имена в `js/data.js`.

## Как добавить товар

В `js/data.js` скопируйте любой блок товара и поменяйте поля: `id` (уникальный, латиницей), `cat` (id категории), `title`, `subtitle`, `price`, `img` (имя файла без `.jpg`), `desc`, `specs`, `colors`. Положите в `assets/img` две картинки: `имя.jpg` и `имя-sm.jpg`.
